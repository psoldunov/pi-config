# JavaScript / TypeScript

- Use spread for immutable object updates; async/await with try/catch for error handling.
- Use Zod for schema validation. No production `console.log`; use a proper logger.
- Use Playwright for critical-flow E2E tests and available E2E specialist guidance.
- React effect timers (for example debounce) must be cleared in effect cleanup. React hooks do not require Pi lifecycle documentation.
