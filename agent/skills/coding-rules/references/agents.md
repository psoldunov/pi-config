# Specialist Work

Use the closest available skill, workflow, or permitted sub-agent; role names are not promises that named agents exist. Host rules decide whether to delegate; don't spawn merely to satisfy this card.

Match roles proactively: planner for complex features/refactors; architect for design; TDD guide for features/fixes; reviewer after coding; security reviewer before commits; build diagnostician for failures; E2E runner for critical flows; refactor cleaner for maintenance; documentation updater for docs.

When delegation is permitted, parallelize independent work. For complex problems use factual, senior-engineering, security, consistency, and redundancy perspectives. Avoid duplicate context and unnecessary specialist launches when the host's own workflow or a skill covers the role.
